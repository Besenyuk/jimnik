# Jimny Launcher — збірка APK

## Варіант А: без комп'ютерних програм (GitHub)
1. Створіть новий репозиторій на github.com і завантажте вміст цієї папки (Add file → Upload files).
2. Відкрийте вкладку **Actions** — збірка запуститься сама (~3 хв).
3. Відкрийте завершений запуск → внизу **Artifacts → JimnyLauncher-apk** → скачайте zip, всередині APK.

## Варіант Б: Android Studio
File → Open → ця папка → Build → Build APK(s).

## Встановлення на магнітолу
1. Скиньте APK на флешку, відкрийте файловим менеджером на магнітолі.
2. Дозвольте встановлення з невідомих джерел.
3. Запустіть «Jimny Launcher». Щоб зробити його головним екраном — натисніть «Додому» і виберіть його → «Завжди».

Дизайн лежить у app/src/main/assets/index.html — після змін просто замініть цей файл і зберіть знову.
